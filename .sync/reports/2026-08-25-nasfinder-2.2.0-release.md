# NasFinder 2.2.0 release

- Product version: 2.2.0
- Common build: 202608252025
- Android versionCode: 341065
- Release candidate started: 2026-08-25 20:25 KST

## Included changes

- Super Thumbnail video frame selection uses 3/13 and retries at 6/13 only when at least 50% of the primary frame is black.
- Folder Super Thumbnails receive one final 1.5pt blur without cumulative parent-folder blur.
- Stored Super Thumbnails remain ahead of ordinary thumbnail sources.
- Android publishes navigation state before remote I/O so connection taps and both Back controls respond immediately.
- Mac themes never invoke unsupported alternate-icon APIs; Mac keeps one fixed icon and hides the icon picker.
- Designed-for-iPad on Mac and Mac Catalyst use the 2x Mac presentation scale for text, controls, rows, icons, spacing, and content width.
