# Google 포토 일반 페이지 전환 — 2026-10-16

- 사용자 요청: Google 포토 팝업을 앱 안의 일반 페이지로 변경.
- Apple 2.9.0 → 2.9.1, 빌드 202610162134. iPhone 및 Mac 빌드·데이터 유지 교체 설치·실행 완료. 실제 설치 버전 및 Mac 서명 정상 확인.
- 대시보드·받은 파일·폰하드 파일 화면의 Google 포토 진입을 navigationDestination으로 변경. 선택 웹 화면도 같은 NavigationStack의 페이지로 이동하며, 시스템 뒤로가기 사용. 중첩 NavigationStack 및 수동 UIKit 모달 표시 제거.
- 선택 페이지로 이동할 때 기존 가져오기 작업을 취소하지 않고, 선택 완료 시 가져오기 결과 페이지로 돌아오도록 처리. 사용자가 원래 진입 페이지를 나가면 기존 취소·세션 정리 동작 유지.
- WKWebView의 상하단을 안전 영역에 맞춰 Google 완료 버튼과 선택 개수가 앱 상단 바/홈 영역에 가려지지 않도록 수정.
- 로그인 유지 확인: iPhone 로그인 후 여러 번 교체 설치·재실행을 거쳐 Google 목록에 재로그인 없이 접근. Mac도 같은 방식으로 재로그인 없이 내부 목록 표시.
- 실제 화면: iPhone과 Mac 모두 팝업 없는 일반 페이지와 뒤로가기 확인. Mac 선택 페이지에서 뒤로가기→선택 대기 페이지→취소→대시보드 복귀 확인.
- iPhone에서 사용자가 선택했던 10월14일 사진4장을 새 선택 세션에 같은 항목으로 다시 선택, Google 완료 버튼 실행→4개 가져오기 성공/실패0. 가져온 4장만으로 4장면7초 예고편 생성 및 움직이는 재생 확인. 완료 후 Google 결과 페이지→완료 버튼→대시보드 복귀 확인.
- Android는 기존 일반 페이지 및 네이티브 Google 포토 선택을 유지(2.9.0). 앞선 Google 최신 사진1+동영상1→7초, 달력10월15일 사진2장→4초 제작·재생 성공.
- 테스트 러너·공개 릴리즈·Git 커밋/푸시 없음. 원본 변경 없음. Linear 기록은 기존 워크스페이스 사용량 제한으로 미기록, 로컬 보고 보존.
