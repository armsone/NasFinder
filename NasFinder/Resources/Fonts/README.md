License risk notes:
- OFL fonts: Kakao Big Sans, Nanum Gothic, Pretendard, Tenada, Gowun Dodum,
  Gowun Batang, Black Han Sans, and Do Hyeon are handled as SIL Open Font
  License 1.1 fonts. Keep each OFL/copyright notice with redistributed font
  files. Do not sell the font files by themselves. Do not use reserved font
  names for modified versions unless the license holder permits it.
- MaruBuri: handled under NAVER/NAVER Cultural Foundation font license notes.
  Keep the copyright/license notice with redistributed files and do not sell
  the font file by itself.
- Cafe24 Ssurround: Cafe24's official help says commercial use, video/subtitle
  use, software bundling, and program/app embedding are allowed. Do not sell
  the font file by itself; keep the license notice.
- Puradak Gentle Gothic: the official/usage-guide text allows commercial and
  non-commercial use, video subtitles, app UI, and bundling/redistribution
  with the full notice. Keep the notice and do not sell the font file by
  itself.
- Ddulgi Mayo: the creator's official blog states personal/corporate
  commercial use and free use are allowed, but it does not provide an
  OFL-style detailed redistribution license. HanClip bundles the unmodified
  official OTF with this notice. Treat it as the first legal-review/removal
  candidate if stricter app bundling or redistribution evidence is required.
- Paperlogy and Poppins are bundled under the SIL Open Font License 1.1. Keep
  their copyright and OFL notices with the redistributed font files.
- NEXON Lv.1 Gothic is the unmodified official TTF. NEXON permits commercial
  use and software bundling/embedding when its copyright notice is included;
  do not modify the file or sell it by itself.
